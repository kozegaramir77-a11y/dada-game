# DADA GAME

## اجرا
1. Node.js نسخه 20 یا جدیدتر نصب باشد.
2. در پوشه پروژه اجرا کنید: `npm install`
3. سپس اجرا کنید: `npm start`
4. در مرورگر باز کنید: `http://localhost:3000`

برای انتشار، کل محتویات این پروژه را در ریشه مخزن GitHub آپلود کنید و مخزن را در یک هاست Node.js مانند Railway متصل کنید.
